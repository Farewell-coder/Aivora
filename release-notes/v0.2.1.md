# Aivora v0.2.1 · 全新界面与设计系统

这一版重做了整个界面：**一套设计令牌 + 一层基础组件**，替换掉旧界面里
「每条内容各包一张卡、字号圆角各处手写」的做法。

**只改界面**，数据结构、加密参数与 AEX 协议一行未动，可直接覆盖升级，
你的配置、检测结果、导出记录、备份全部照旧。

---

## 为什么重做

旧界面的问题不是配色不好看，而是**两种内容被迫共用一套排版**：

- 48 处内联字号、7 种圆角、6 种半透明度并存 —— 同一屏里两种字号，
  同类内容两种圆角，改一处观感就漂一次
- 「可用 / 不可用 / 等待检测 / 检测中」全是同一档灰字，必须逐个读字才能分辨
- Endpoint、HTTP 状态码、响应耗时被压成 11sp 灰字 ——
  一个管理端点与密钥的工具，最该看清的东西反而最小最淡
- 所有内容都包成同样的卡片，视觉上无法区分重要度

## 设计系统

### 一套令牌，不再各处手写

配色、字号、圆角、间距、描边、动效收进同一处。

- **浅色与深色是两套独立设计**，不是把一套色值反过来
- 深色档的强调色提亮，其上的文字改用深底字：
  白字压在提亮的蓝上只有 2.47:1，读不了
- 字号收敛为 8 档，**最小 12sp**

### 状态终于看得见

四种语义色（成功 / 警告 / 危险 / 信息）加状态点：
**实心点**是已确定的终态，**空心点**是进行中 —— 不靠颜色也能分辨。

### 技术数据与正文分开

Endpoint、模型 ID、凭证、HTTP 状态码、响应耗时改用等宽字体。
这些内容需要逐字符比对，等宽能让 `0` 和 `O`、`1` 和 `l` 分得清，耗时列能对齐。

### 不再每条内容各包一张卡

容器分成三档：页面区块、列表行、弱化说明。
**行直接铺在区块里**，靠分隔线区分，而不是把每条配置都包成一张同样的卡。

## 页面

- **服务配置**：条目改成行结构，操作从 4 个平铺图标收进一个「更多」菜单，误触少一半
- **密钥检测**：每个模型一行，状态、状态码、耗时、错误摘要各有明确位置，检测进度可见
- **导出记录**：凭证升为独立区块，等宽显示、可选中、可复制
- **设置**：按「行为 / 外观 / 数据 / 关于」分组
- **适配协议**：协议参数从一大段换行文本改成可读的数据行
- **所有弹窗**：配置编辑、导出、导入预览、凭证输入、记录详情改为底部弹层，
  长表单和多候选预览不再挤在小弹窗里

## 更快

配置、检测结果、导出记录、导入候选全部改成惰性列表并设稳定 key，
条目多时不再一次性构建全部行。

## 本版修掉的问题

- **次按钮的边框比填充块小一圈**，看起来像「按钮超出了自己的边框」
  —— 修饰符顺序写错，描边画在了内缩后的内容盒上
- **检测结果是灰字**：成功状态和失败状态应当同样醒目，原来只有失败走色
- 状态标签、按钮、底栏标签在文字超宽时被**硬裁切**，边界切在字形中间
- 适配协议页的长标签（「密钥派生」等）压到右侧数值上
- 导入预览的来源名（「Cherry Studio」）与徽标挤在一行，窄屏被撑爆
- 记录时间、可展开区块副标题、设置行标题会把整行撑高

## 顺带修掉的真问题

- 深色主题下锁定页的锁图标几乎看不见（写死了浅色档的品牌色）
- 冷启动时启动窗口底色与应用内背景不一致，会闪一下
- 系统栏图标颜色在 XML 与运行时两处设置、互相打架
- 弱化面板与页面底色差过小，几乎看不出是一块面

## 验证

- 单元测试 77 个全过，含 **32 条配色对比度断言**（配色改动会立刻失败）
- 新增静态门禁：样式裸值、旧组件残留、过小字号、配色对比度四道检查
- 真机双主题像素采样：两套配色的实际渲染值与设计令牌**逐一命中**
- 已走查六个页面、五个弹层、菜单、键盘避让与主题切换

完整设计规范见 `docs/DESIGN_SYSTEM.md`。
