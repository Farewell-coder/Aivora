# v0.0.9 · 交互重做

这一版只动界面与交互，**不涉及数据结构、加密参数和 AEX 协议**：配置、导出记录、备份文件全部照旧，可以直接覆盖升级。

## 六项交互

**按下有反馈**
按钮、卡片、底部导航按下时会轻微缩放，松手回弹；切页和长按多选有轻触感反馈。

**勾选能联动**
多选模式下，全选框变成三态：全没选、选了一部分（中间横杠）、全选了。被选中的卡片描一圈主色边，「导出所选」「删除所选」在没选中任何东西时自动变灰。

**卡片平滑展开**
设置页的折叠卡片改成平滑撑开，箭头跟着旋转 180°，整行都可以点，不再只有右侧小箭头有效。

**编辑变成底部面板**
「新建 / 编辑配置」从屏幕中间的对话框改成从底部滑出的面板，可以按住往下甩关闭，甩到一半松手会自动吸回去。输入时键盘不再把字段挤变形。

**滚动更顺**
配置页和导出记录页换成惰性列表，只渲染屏幕上看得见的条目，条目多了也不卡。

**换页有转场**
点底部导航切换页面时，新页面从底部中心向外扩散铺开，320 毫秒。

## 视觉统一

- 深浅两套配色补齐容器层级，深色模式下卡片不再糊成一片
- 圆角、间距、字号收敛成一套 token，卡片分「淡底」「描边」两级
- 空状态统一成图标 + 说明 + 主操作按钮
- 标题栏固定，不再随列表滚走

## 已知限制

- 尚不支持拖动排序（需要给配置表加排序字段，不在本版范围）
- 密钥检测页仍是普通滚动列表，未做惰性化

## 验证

- 单元测试与构建由 CI 完成
- 本版未改动 `ServiceConfig` / `ExportRecord` 表结构，升级不会丢数据

适用架构：arm64-v8a　·　系统要求：Android 8.0（API 26）及以上
