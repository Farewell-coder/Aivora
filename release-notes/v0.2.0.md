# Aivora v0.2.0 · 设计系统重做

这一版重建了整个视觉体系：**一套设计令牌 + 一层基础组件**，替换掉旧界面里
「每条内容各包一张卡、字号圆角间距各处手写」的做法。

**只改界面**，不涉及数据结构、加密参数与 AEX 协议，可直接覆盖升级。
配置、导出记录、备份全部照旧。

---

### 一套令牌，不再各处手写

配色、字号、圆角、间距、描边、动效收进同一处。旧界面有 48 处内联字号、
7 种圆角、6 种半透明度并存 —— 同一屏里两种字号、同类内容两种圆角，改一处观感就漂一次。

- 浅色 / 深色是**两套独立设计**，不是把一套色值反过来
- 深色档的强调色提亮，其上的文字改用深底字：白字压在提亮的蓝色上只有 2.47:1，读不了

### 状态终于看得见了

以前「可用 / 不可用 / 等待检测 / 检测中」全是同一档灰字，必须逐个读字才能分辨。

现在有四种语义色（成功 / 警告 / 危险 / 信息）加状态点：
**实心点**表示已经确定的终态，**空心点**表示进行中 —— 不靠颜色也能分辨。

### 技术数据与正文分开

Endpoint、模型 ID、凭证、HTTP 状态码、响应耗时改用等宽字体。这些内容需要逐字符比对，
等宽能让 `0` 和 `O`、`1` 和 `l` 分得清、耗时列能对齐。

此前这些信息被压成 11sp 灰字 —— 一个管理端点与密钥的工具，最该看清的东西反而最小最淡。

### 不再每条内容各包一张卡

容器分成三档：页面区块、列表行、弱化说明。**行直接铺在区块里**，靠分隔线区分，
而不是把每条配置、每个模型、每个设置项都包成一张同样的卡片。

旧版所有内容都长一样，视觉上无法区分重要度。

### 页面

- **服务配置**：条目改成行结构，操作从 4 个平铺图标收进一个「更多」菜单，误触少一半
- **密钥检测**：每个模型一行，状态、状态码、耗时、错误摘要各有明确位置，检测进度可见
- **导出记录**：凭证升为独立区块，等宽显示、可选中、可复制
- **设置 / 关于 / 适配协议**：按语义分组；协议参数从一大段换行文本改成可读的数据行
- **所有弹窗**：配置编辑、导出、导入预览、凭证输入、记录详情改为底部弹层，
  长表单和多候选预览不再挤在小弹窗里

### 更快

配置、检测结果、导出记录、导入候选全部改成惰性列表并设稳定 key。
条目多的时候不再一次性构建全部行。

### 顺手修掉

- 深色主题下锁定页的锁图标几乎看不见
- 冷启动时启动窗口底色与应用内背景不一致，会闪一下
- 快速切换页面时偶尔丢失滚动位置与搜索词
