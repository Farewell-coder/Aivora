# AEX 生态适配

本页记录声称支持 AEX 的第三方软件。**列表由项目方或第三方开发者主动提交，未经 Aivora 团队逐一验证的项目不会被标记为"已验证"。**

> 当前状态：AEX 1.1 已随 Aivora 0.0.8 实现。文件通道（`.akcp`）自 0.0.5 起可用，深链通道自 0.0.8 起可用。目前 **Dollhouse** 已完成 AEX 1.1 适配（自行声明），欢迎其它软件按下方模板提交。

## 适配状态说明

| 状态 | 含义 |
|---|---|
| `已验证` | Aivora 团队用公开测试向量实际跑通导入，且提交方提供了可复现的验证记录 |
| `自行声明` | 提交方声明已完成适配，Aivora 未独立验证 |
| `开发中` | 已知该软件正在适配，尚不可用 |
| `计划中` | 已登记意向，未开始实现 |

## 已适配列表

| 软件名称 | 项目仓库 | 通道 | AEX 版本 | 最低软件版本 | 导入能力 | 适配状态 |
|---|---|---|---|---|---|---|
| Dollhouse | [Farewell-coder/Dollhouse](https://github.com/Farewell-coder/Dollhouse) | 文件+深链 | 1.1 | 0.2.2 | 单配置 / 多配置 / 全量集合 | 自行声明 |

> 「通道」一列填 `文件` / `深链` / `文件+深链`。深链需要在 Aivora 的接收方注册表中登记 scheme 与 host，才会出现在应用的软件选择列表里。Dollhouse 的登记为 `dollhouse://aivora-import`。
>
> **Dollhouse 补充说明**：文件通道兼容等级 **2**（`extra` 可读但当前不落库，预览会提示）；未知字段保留在解析模型中；冲突处理支持跳过 / 覆盖 / 另存副本。官方 1.1 测试向量已纳入其单测，深链覆盖 `AEX-DEEPLINK.md` §6 的必测用例。Dollhouse 0.2.2 已发布：<https://github.com/Farewell-coder/Dollhouse/releases/tag/v0.2.2>。因尚未经 Aivora 团队独立复核，状态标为「自行声明」。

## 提交适配信息

请新建 Issue，标题格式 `[AEX Adapter] <软件名称>`，并填写：

```markdown
- 软件名称：
- 项目仓库 / 下载地址：
- 支持的通道：[ ] 文件（.akcp）  [ ] 深链
- 支持的 AEX 版本：1.1
- 最低软件版本：
- 文件通道兼容等级：1 / 2 / 3（不做文件通道可留空）
- 深链 scheme / host：（做了深链才填，例如 dollhouse / aivora-import）
- 支持的导入能力：
  - [ ] 单配置
  - [ ] 多配置
  - [ ] 全量集合
- 模型列表获取：自行请求 /models（1.1 要求）
- 未知字段处理：保留 / 丢弃（丢弃需说明）
- 冲突处理：跳过 / 另存副本 / 替换
- 验证记录：（测试向量编号 / 深链必测用例 + 实际结果）
- 适配状态：自行声明 / 开发中 / 计划中
```

提交后由维护者核对，符合要求者更新到上表，并把深链 scheme 加进 Aivora 的接收方注册表。若提供验证记录，可申请标记为 `已验证`。

## 关于未适配的软件

未适配 AEX 的软件**不受影响**，其原有功能保持不变，只是无法直接接收 Aivora 分享的 `.akcp` 文件。用户仍可通过手动复制 Endpoint 与 API Key 的方式迁移。Aivora 不要求、也不强制任何软件适配 AEX。
