# AEX 生态适配

本页记录声称支持 AEX 的第三方软件。**列表由项目方或第三方开发者主动提交，未经 Aivora 团队逐一验证的项目不会被标记为"已验证"。**

> 当前状态：AEX 1.0 已随 Aivora 0.0.5 实现并可用 `.akcp` 文件联调。目前**尚无第三方软件完成适配**，因此列表为空——这不是缺陷，而是生态刚起步。欢迎按下方模板提交。

## 适配状态说明

| 状态 | 含义 |
|---|---|
| `已验证` | Aivora 团队用公开测试向量实际跑通导入，且提交方提供了可复现的验证记录 |
| `自行声明` | 提交方声明已完成适配，Aivora 未独立验证 |
| `开发中` | 已知该软件正在适配，尚不可用 |
| `计划中` | 已登记意向，未开始实现 |

## 提交适配信息

请新建 Issue，标题格式 `[AEX Adapter] <软件名称>`，并填写：

```markdown
- 软件名称：
- 项目仓库 / 下载地址：
- 支持的 AEX 版本：1.0
- 最低软件版本：
- 兼容等级：1 / 2 / 3
- 支持的导入能力：
  - [ ] 单配置
  - [ ] 多配置
  - [ ] 全量集合
- 未知字段处理：保留 / 丢弃（丢弃需说明）
- 冲突处理：跳过 / 另存副本 / 替换
- 验证记录：（测试向量编号 + 实际结果）
- 适配状态：自行声明 / 开发中 / 计划中
```

提交后由维护者核对，符合要求者更新到上表。若提供验证记录，可申请标记为 `已验证`。

## 关于未适配的软件

未适配 AEX 的软件**不受影响**，其原有功能保持不变，只是无法直接接收 Aivora 分享的 `.akcp` 文件。用户仍可通过手动复制 Endpoint 与 API Key 的方式迁移。Aivora 不要求、也不强制任何软件适配 AEX。

## 关于旧格式

已适配旧版 AKCP 1.0（`.aivora`）的软件可以继续工作。AEX 上线后，旧格式仍保留导入与导出能力，但不再新增特性。旧软件若希望迁移到 AEX，属于独立的新增适配工作，两者凭证不通用。
